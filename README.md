# RAG-Evaluation: RAG 모델 평가 도구

## 프로젝트 소개

이 프로젝트는 검색 증강 생성(Retrieval-Augmented Generation, RAG) 모델의 성능을 평가하기 위한 포괄적인 도구 모음입니다. RAG는 대규모 언어 모델(LLM)이 외부 지식 베이스를 참조하여 보다 정확하고 신뢰성 있는 답변을 생성하도록 하는 기술입니다. 이 프로젝트는 RAG 파이프라인의 각 구성 요소를 벤치마킹하고 성능을 분석하며, 결과를 시각화하는 프레임워크를 제공합니다.

## 주요 기능

*   **End-to-end RAG 평가:** 검색부터 생성까지 RAG 파이프라인 전체를 평가합니다.
*   **다양한 평가 지표:** 검색 정확도, 생성 품질 등 RAG 성능의 다양한 측면을 평가하기 위한 여러 지표를 제공합니다.
*   **유연하고 확장 가능한 구조:** 특정 요구에 맞게 평가 프레임워크를 쉽게 사용자 정의하고 확장할 수 있습니다.
*   **웹 기반 사용자 인터페이스:** 직관적이고 상호작용적인 웹 인터페이스를 통해 평가 결과를 시각화하고 분석할 수 있습니다.
*   **확장성 및 안정성:** 마이크로서비스 아키텍처로 구축되어 대규모 평가를 처리할 수 있도록 설계되었습니다.

## 프로젝트 구조

```
.
├── DB
├── parasite_library
├── RAG_Evaluation
├── Redis-DB
└── UI
```

*   **`DB`:** RAG 시스템에서 사용하는 데이터를 저장하기 위한 MongoDB 데이터베이스 관련 설정 파일이 포함되어 있습니다.
*   **`parasite_library`:** 데이터 처리, 보고서 생성 및 프롬프트에 사용되는 파이썬 라이브러리입니다.
*   **`RAG_Evaluation`:** FastAPI 백엔드, Redis 캐싱, 다양한 평가 지표를 포함하는 핵심 평가 구성 요소입니다.
*   **`Redis-DB`:** 캐싱을 위한 Redis 데이터베이스 관련 설정 파일이 포함되어 있습니다.
*   **`UI`:** 평가 결과를 보여주는 React 기반의 프론트엔드 애플리케이션입니다.

## 프로젝트 실행 방법

### 사전 준비

*   Docker
*   Docker Compose

### 설치

1.  **저장소 복제:**
    ```bash
    git clone https://github.com/your-username/RAG-Evaluation.git
    ```
2.  **Docker 이미지 빌드:**
    ```bash
    docker-compose build
    ```

### 실행

Docker Compose를 사용하여 애플리케이션을 시작합니다.

```bash
docker-compose up
```

모든 서비스가 시작되면 `http://localhost:5173`에서 UI에 접속할 수 있습니다.

## 사용 방법

1.  **웹 인터페이스 접속:** 브라우저에서 `http://localhost:5173`으로 접속합니다.
2.  **평가 설정:** 평가할 데이터셋, RAG 파이프라인, 사용할 평가 지표 등 평가에 필요한 파라미터를 설정합니다.
3.  **평가 시작:** 설정을 완료한 후 평가를 시작하고 웹 인터페이스에서 진행 상황을 모니터링합니다.
4.  **결과 분석:** 평가가 완료되면 웹 인터페이스에서 결과를 확인하고 분석할 수 있습니다.
